# Uçan Veysi 🪂

Düşen Veysi kafalarını yakala! Kombo yap, güçlendiricileri topla, bombalardan kaç.

## Oyna
https://beso1719.github.io/ucan-veysi/

## Kontroller
- 📱 Dokun ve kaydır
- 💻 Fare veya ← → ok tuşları

## Özellikler
- Kombo ve puan çarpanı
- Güçlendiriciler: 🌟 Altın Veysi, ❤️ can, ⭐ yavaş çekim
- 💣 Bombalardan kaçın
- Fotoğraflar daire içinde ortalanmış (cover-fit)
- Rekor kaydı (localStorage)
